# GTA 2（Grand Theft Auto 2，1999）

## 1. 一句話介紹
2D 時代的第二款，舞台換成一座不對應任何真實城市的復古未來都市。

## 2. 基本資料
| 項目 | 內容 |
|---|---|
| 發售年份 | 1999（Windows）[raw/01] |
| 平台 | Windows；之後移植到 PlayStation、Dreamcast、Game Boy Color [raw/01] |
| 開發商 | 待查 |
| 城市 | Anywhere City，虛構的美國復古未來（retro-futuristic，用過去的想像描繪未來）都市，沒有明顯的真實城市原型 [raw/01] |
| 故事年代 | 未明確：不同來源說法從「三週後的未來」到 2013 年都有，遊戲內又暗示是 1999 年 [raw/01] |
| 主角 | 待查 |
